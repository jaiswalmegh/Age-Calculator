
# ✨ AURORA | Age Intelligence

A modern, dark-themed Age Calculator built using Python, CustomTkinter, and TkCalendar. Calculate your exact age through a beautiful desktop GUI with detailed statistics and birthday insights.

## 🚀 Features

- 🎂 **Exact Age Calculation:** Years, months, and days
- 📅 **Interactive Date Picker:** Easy date-of-birth selection
- 📊 **Age Statistics:** Total months, weeks, days, and hours
- 🎉 **Birthday Countdown:** Days remaining until your next birthday
- ♈ **Zodiac Profile:** Zodiac sign based on date of birth
- 🛡️ **Input Validation:** Prevents future birth dates
- 🐍 **Python-Powered:** Simple, modular, and easy to maintain
- 🌙 **Premium Dark UI:** Modern dashboard with contrasting colors
- 🔒 **Privacy-Friendly:** Calculations run locally without a database or external API

## 🛠️ Tech Stack

- Python
- CustomTkinter
- TkCalendar
- Python Standard Library

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/jaiswalmegh/Age-Calculator
cd YOUR_REPOSITORY_NAME
```

Replace the placeholders with your actual GitHub repository URL and folder name.

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Run the application

```bash
python main.py
```

## 🧠 How It Works

1. Select your date of birth using the calendar.
2. Calculate your exact calendar age.
3. View total elapsed days, weeks, months, and hours.
4. Check your next birthday countdown.
5. Explore your birthday profile.

The age calculation accounts for variable month lengths and leap years rather than treating every month as a fixed number of days.

## 🔐 Privacy

This application performs calculations locally. It does not require an account, send birth-date information to an API, or save personal information to a database.
